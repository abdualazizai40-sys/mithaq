# ميثاق الأداء للمراقبين

نظام متابعة ميثاق الأداء السنوي للمراقبين، بثلاث واجهات: المراقب، المشرف، المدير.

## التشغيل

الموقع صفحة واحدة (`index.html`) تُنشر عبر GitHub Pages، والبيانات في قاعدة بيانات Supabase (مشروع `mithaq-aladaa`).

- المراقب والمشرف: يختار اسمه ويكتب رقمه السري. المدير يعيّن لكل شخص رقماً أولياً، ويطلب النظام تغييره في أول دخول.
- المدير: يدخل برمز المدير. أول رمز يُكتب بعد النشر يصبح رمز المدير.

## الحساب

- الدرجة سنوية تراكمية من 5 = مجموع العمليات × وزن العملية + كل خانة أخرى × وزنها.
- مجموع العمليات = ناتج الزيارات + ناتج البلاغات، وناتج كل منهما = المجموع × نسبة الجودة.
- المطلوب السنوي: العمليات، القراءات التموينية، الضبطيات، جودة الزيارات، جودة البلاغات.
- كل الأرقام (الأوزان، الأهداف، المستويات، سنة الميثاق، مواعيد الإرسال) يعدّلها المدير من «المعادلة والمستهدفات».

## الصلاحيات

- المراقب يرى ميثاقه فقط، ويرسل أعمال الشهر في نهايته.
- المشرف يرى مراقبيه، يكتب ملاحظاته، وينزّل تقارير PDF.
- المدير يرى الجميع ويدير الأسماء والمعادلة.
